# Power-BI-Chicago-Seasonal-Crime-s-Report-Dashboard
this project presents the quarterly Analysis of Crime cases, Arrested crime and  Domestics crime using KPI and Interactive charts.

# Project Highlights
- this project reveals that the 4th quarter of the year report for the highest crime committed of 583,575.
- this project show the quarterly Arrested and reported crime trends from 2018 to 2021.
- this project displayed the lowest quarterly crime distribution to be 48043.

# Tools and Skills
- Power Query.
- Power Bi.
- Slicer (interactive filter).
- Dashboard designs.
- Visuals and Analytical illustrations..

# Dashboard features
- Total crime By Quarter.
- Arrested crime By Quarter.
- Domestic crime By Quarter.
- arrested and Domestic crime By year Quaters.
- Crime composition By Quater.

# Key Insights 
- Forth quarter of the year recorded the highest amount of crime case committed.
- Forth quarter of the  year recorded the highest number of Arrested crime rate.
- The total number of crime reported cases is 945,846 from 2018 to 2021.
- The total number of arrested crimes during the period of reported years is168,098.
- Year 2021 2nd quarter,  as the highest number of reported domestic crime case.

# Recommendations
- There should be an increase in police patrol and security presence during 4th Quarter of  the year since crime level are more  during that time.
- Improve response and supporting system should be provided to also reduce domestic-crime cases rate.
- Police and other security should use crime graph trends as guide in their security planning, staffing and resource allocation of duties.
- Preventives and community policing activities should be strengthened before high-risk periods.
